New ``vcf_sddc_services_config`` client / module / state for the SDDC Manager ``/v1/services-config`` endpoint (VCF 9.1's replacement for the retired depot-settings API). Ships a ``depot_node`` state that idempotently repoints ``VCF_DEPOT`` at a caller-supplied FQDN/IP plus certificate PEM — useful for pointing SDDC-Mgr at an offline nginx mirror. Notes the LCM validator quirks: PUT body must wrap the list in ``{"services": [...]}``, and address type must be ``Fqdn`` even when the value is a bare IP (``IpAddress`` triggers a server-side NPE).
